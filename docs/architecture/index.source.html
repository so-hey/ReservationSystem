図の読み方

ReactアプリがHonoのHTTP APIを呼び出し、予約データはPrisma経由でPostgreSQLへ保存します。返却画像はHonoからSupabase Storageへアップロードし、その公開URLを予約レコードに保存します。認証は独自の管理者ログインとJWTで、Supabase Authの呼び出しは確認できません。

確認できた処理と、未確認の境界

メールは管理画面でGmailまたはメールアプリの作成画面を開きます。Resendは依存関係にありますが、送信処理での使用は確認できません。GitHub ActionsはSupabaseのkeep_alive RPCを定期実行し、空コミットをpushする設定です。デプロイ用CIは確認できません。PostgreSQLとSupabase RPCが同じDBを指すかは、ソースだけでは確定できません。

ソース上の接続に関する補足

ブラウザのJWT送信と、サーバーの管理者認可は別です。予約ルートでは認可がTODOのままです。また返却フォームの送信キー damageDetails / returnImages と、APIの受信キー damage_details / return_images が一致していません。この図はコード上の処理経路を示し、結合動作の成功を保証するものではありません。
