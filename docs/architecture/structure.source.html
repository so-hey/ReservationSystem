フォルダの役割

フロントエンドは機能別構成です。app/ が画面全体の組み立て、features/ が予約・認証・管理、shared/ が共通UIと型・定数・ユーティリティを担当します。図の矢印は主要な参照・呼び出しを示し、すべてのimportを網羅するものではありません。

READMEとの差分

作成時のREADMEにはReact 18とありましたが、package.jsonの宣言はReact 19です。フロントエンドREADMEも19へ更新済みです。またlib/ は作成時のREADMEでは削除予定とされていましたが、予約・管理・認証のフックから現在も参照されています。features/reservation/api/reservationApi.tsとshared/api/index.tsの経路も存在するため、通信実装は二系統あります。

バックエンド

server.ts はPostgreSQLへの接続を確認してからNode.jsでHonoを起動します。index.ts が3系統のルートを登録し、routes/ が utils/ のPrisma、JWT、Supabaseクライアントを使います。prisma/ はDBスキーマとマイグレーションです。

主な根拠

両ディレクトリのpackage.json、ReservationSystem/src/app/、src/features/*/hooks/、src/lib/、src/shared/、ReservationSystemBack_Hono/src/server.ts、src/index.ts、src/routes/、src/utils/。
